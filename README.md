# אתר האמן אברהם שמי־שהם

אתר סטטי + עורך תוכן, מתארחים בחינם ב־GitHub Pages.

- **האתר**: https://kobik-hub.github.io/abraham-shemi-shoham/
- **העורך**: https://kobik-hub.github.io/abraham-shemi-shoham/editor/

## איך העריכה עובדת

העורך הוא עמוד סטטי שכותב ישירות למאגר הזה דרך GitHub API:

- כל תוכן האתר (טקסטים, גלריות, כותרות, תערוכות) בקובץ אחד — [content.js](content.js)
- התמונות ב־[assets/art/](assets/art/) — תיקייה לכל גלריה
- כל שמירה בעורך = קומיט. **ההיסטוריה היא הגיבוי** — שום מחיקה אינה אבודה
- תמונות שמועלות מוקטנות בדפדפן ל־1600px לפני השמירה
- GitHub Pages בונה מחדש תוך ~דקה מכל קומיט

## כניסה עם סיסמה (לאמן)

המנהל מגדיר פעם אחת ב־[editor/seal.html](editor/seal.html): מדביק מפתח GitHub,
בוחר סיסמה פשוטה — והמפתח נשמר במאגר מוצפן (PBKDF2 600k + AES-GCM) בקובץ
`editor/secret.json`. מאז, הכניסה לעורך היא בסיסמה בלבד; שכחו אותה — מריצים
את seal.html שוב עם סיסמה חדשה. מומלץ מפתח Fine-grained מוגבל למאגר הזה בלבד.

## חיבור מתקדם (פעם אחת בכל מחשב)

1. פותחים את העורך — מופיע מסך ״חיבור ראשוני״
2. לוחצים על הקישור ליצירת מפתח (נפתח דף GitHub עם ההרשאות הנכונות מראש), לוחצים **Generate token** ומעתיקים
3. מדביקים את המפתח, ממלאים שם משתמש ושם מאגר — והעורך זוכר לתמיד

המפתח נשמר רק בדפדפן של אותו מחשב. בלי מפתח אפשר רק לצפות בעורך, לא לשמור.

## עבודה מקומית (למפתח)

```bash
git pull                       # למשוך עריכות שנעשו דרך העורך
npx serve . -p 9080            # או כל שרת סטטי אחר
```

שינוי מקומי → `git push`, והאתר מתעדכן. לא לערוך במקביל מקומית ודרך העורך בלי pull.
